# `raisim-fast` (`raisim_fast`)

High-throughput C++20 OpenMP vectorized articulated physics engine (`libraisim_fast_vec.so`) and sub-millimeter MJCF-to-Analytical-Primitive URDF compiler built on top of `raisim2Lib` (`v2.16.0+`).

See the repository root [`README.md`](../README.md) for full architecture, benchmarks, and installation instructions.
